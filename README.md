## 🚀 Getting started

1. Download the rootfs image from the [latest release](https://github.com/yakrajkc160-ui/Jasmine/releases/latest).
2. Install the Jasmine app on your ARM64 Android device.
3. Open the app and finish the setup wizard.
4. In **Settings → Personal & Keys**, add your provider key and verify it.
5. Grant the permissions you want — Accessibility unlocks full screen control.
